# SILK HOUSE (Swarnavastra)

A premium Indian luxury silk saree e-commerce brand MVP homepage prototype.

## Design Highlights
- **Royal Indian Palette**: Warm Ivory background (`#FDFBF7`), Regal Deep Maroon (`#3B0A12`), and subtle Gold accents (`#D4AF37`).
- **Typography**: Paired fonts featuring *Cormorant Garamond* (luxury classic serif) and *Montserrat* (clean refined sans).
- **Responsive Layout**: Designed for seamless browsing across desktops, tablets, and mobile devices.

## Features
- **Header**: Brand logo text ("SILK HOUSE"), navigation links (Home, Shop Sarees, About), and cart indicator.
- **Hero Section**: "Timeless Silk. Unforgettable Elegance." with a "Shop Collection" call-to-action button.
- **Saree Collection Showcase**: 5 sample silk saree product cards with INR (`₹`) prices, weave details, and high-resolution imagery with offline SVG fallbacks.
- **Dynamic Category Filters**: Filter by **All**, **Kanchipuram**, **Banarasi**, and **Bridal** powered by vanilla JavaScript.
- **Cart Interactivity**: "Add to Bag" updates cart count with a toast alert.

## Tech Stack
- HTML5
- CSS3 (Vanilla, custom properties & responsive grid)
- JavaScript (ES6+ Vanilla, zero external library dependencies)

## How to Run
Simply open `index.html` in any web browser, or serve it locally using:
```bash
npx serve .
```
